## Featured Projects

### Multimodal AI Agent Architecture with n8n

Workflow architecture built with n8n to process different types of inputs, route requests and coordinate specialized AI agents.

**Main concepts:**

- Multimodal input handling
- AI agent orchestration
- Routing by intent
- API consumption
- Webhooks
- Structured prompts
- Human escalation logic

**Technologies:** n8n, LLMs, APIs, webhooks, AI agents, prompt engineering.

---

### Smart Receptionist for Small Businesses

Automation concept for small businesses that need to manage customer requests, classify messages and reduce repetitive communication.

**Main features:**

- Lead capture
- Message classification
- Automated responses
- Appointment support
- Internal notifications
- Human handoff for complex cases

**Technologies:** n8n, AI agents, webhooks, Google Sheets, APIs, LLMs.

---

### Landing Page + Automation System

A web automation flow where a landing page form is connected to n8n to capture users, validate information and trigger business workflows.

**Main features:**

- Landing page form
- Webhook integration
- Data validation
- Lead registration
- Email notification
- Follow-up automation

**Technologies:** HTML, CSS, JavaScript, WordPress, n8n, APIs, webhooks.

---

### BarberAgency Case Study

SaaS-style project for barbershops focused on appointments, services, barbers, dashboards and automation.

**Main modules:**

- Barbershop registration
- Services management
- Barber management
- Appointment scheduling
- Dashboard structure
- Multi-tenant logic
- Workflow automation

**Technologies:** PostgreSQL, PostgREST, WordPress, APIs, n8n, webhooks, AI-assisted development.
